# uat-v2_022 incident

## 事象
- qwen3.5:122b の 1本目（Next.js Space Invaders）で Plan mode が完了しきらず、`iter 6/50 duration 262s edited 0 files` で割り込み停止した。
- 途中で plan progress 表示は `Approval ready` を出したが、実際の plan file は `Execution Plan` / `Verification Plan` / `Risks / Fallbacks` が空のままで、以降は既存セクションの再編集を繰り返していた。

## 問題箇所
- `src/agent/loop_run/turn.rs`
  - Plan file edit 後、未完了セクション数が減っていない場合でも `plan_progress_retries` を 0 に戻していた。
  - そのため、同じ段階の再編集ループが進捗ありとして扱われ、fallback plan に到達しなかった。

## 根本原因
- Plan mode の進捗判定が「plan file を編集したか」を重視しすぎており、「必要セクションが埋まったか」を十分に見ていなかった。
- local LLM が空の stage 3 セクションを残したまま stage 1/2 を再編集するケースで、収束判定が働かなかった。

## 対策案
- Plan file edit 前後で `plan_missing_sections` の数を比較し、減っていない edit を非進捗として扱う。
- 非進捗 edit が連続したら deterministic fallback plan を materialize して、Act mode に進める。

## 対策案詳細（仕様）
- Plan turn 開始時に未完了セクション数を記録する。
- Plan file edit 後に未完了セクション数が減った場合のみ `plan_progress_retries` を reset する。
- 減っていない場合は recovery note を追加し、2回目で `materialize_deterministic_fallback_plan("agent.plan.non_progress_edit_fallback_materialized")` を実行する。
