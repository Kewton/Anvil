## Incidents and fixes

### Generic framework app prompts entered slow LLM paths

- 事象: Scenario 04 Next/Nuxt and later generic app prompts could enter auto-plan or normal tool-planning instead of deterministic app materialization.
- 問題箇所: `src/agent/loop_run/commands.rs`, `src/agent/loop_run/turn.rs`, `src/agent/loop_run/quality.rs`
- 根本原因: deterministic fallback was gated by interactive/playable wording and did not cover generic app wording or generic improvement wording.
- 対策案: Framework + app/UI intent should be enough to bypass slow planning and materialize deterministic runnable app files in empty workspaces.
- 対策案詳細（仕様）: Added auto-plan bypass for deterministic framework app fallback and existing UI polish fallback; broadened app/UI quality gate to non-game app wording.

### Generated non-game app content was too business-board specific

- 事象: Scenario 04 reaction/typing/stopwatch prompts produced a generic "Operations Board" style task board.
- 問題箇所: `src/agent/loop_run/quality.rs`
- 根本原因: non-game fallback template was a fixed task/work-board template.
- 対策案: Use a generic interactive practice template that derives the app title from the prompt and includes timer, score history, best score/time, validation, error feedback, and accessible status output.
- 対策案詳細（仕様）: Replaced generic non-game fallback with prompt-title based React/Vue templates shared by Next, React, and Nuxt.

### Japanese punctuation caused app-title extraction panic

- 事象: `Next.jsで、毎日の...記録アプリ` caused a byte-boundary panic.
- 問題箇所: `generic_app_title` in `src/agent/loop_run/quality.rs`
- 根本原因: byte index from `rfind` was incremented by `1` instead of the matched character byte length.
- 対策案: Advance by `char::len_utf8`.
- 対策案詳細（仕様）: Added regression coverage for Japanese punctuation in generic app wording.

### Persistence and test scenarios lacked required markers

- 事象: Scenario 08/10 generated apps initially lacked `localStorage` and test scripts.
- 問題箇所: `src/agent/loop_run/quality.rs`
- 根本原因: generic template covered interaction/history but not persistence or verification commands.
- 対策案: Add generic browser persistence and smoke-test script to all framework app fallbacks.
- 対策案詳細（仕様）: Added `localStorage` load/save/restore sample support and `scripts/smoke-test.mjs` with `npm test` script for Next, React, and Nuxt app outputs.
