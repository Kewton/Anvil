## 1. 下記ディレクトリ直下に、uat-v2_NNN（Nはテスト回数）ディレクトリを作成
```

```

## 2. 下記コマンドよりanvilを起動
 - まずは下記の通りqwen3.5:122bモデルで品質が安定するまでテストを実施
```
anvildev -m qwen3.5:122b -y --sidecar-model qwen3.5:9b --auto-plan
```
 - 品質安定後下記の通りqwen3.6:27b-coding-nvfp4モデルで品質が安定するまでテストを実施
```
anvildev -m qwen3.6:27b-coding-nvfp4 -y --sidecar-model qwen3.5:9b --auto-plan
```

## 4. anvilからのレスポンスを1分間隔で確認

## 5-1. 途中で停止している場合

1） 下記内容で workspace/v0.1.0/uatspace/uat-v2_NNN.md にインシデントファイルを作成
```
- 事象
- 問題箇所
- 根本原因
- 対策案
- 対策案詳細（仕様）
```

2） インシデントファイルをレビュー・修正

3） インシデントファイルに記載の対策案実施

4） コミットして下記コマンドを実行

```
cargo build --release
```
5-1-5. 手順1から再度実行

## 5-2. 最後まで出力し切った場合

5-2-1. 3011ポートで起動中のプロセスを削除し下記コマンドを実行
```
npm run dev -- -p 3011
```
