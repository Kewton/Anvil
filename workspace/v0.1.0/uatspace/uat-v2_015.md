## Cause

The quality gate can now detect template-quality output at the right time, but recovery still depends on the model producing the next concrete tool call. For this Qwen 3.5 path, the recovery note was not enough to force a substantial `Write`/`Edit`; the loop remained vulnerable to long thinking and read-only churn after a detected scaffold placeholder.

## Countermeasure

Add a deterministic playable-UI fallback for the Space Invaders Next.js path. When the quality gate detects that `app/page.tsx` is still placeholder output for a Space Invaders app request, apply a compact runnable `Write` tool fallback that replaces the page with a playable canvas-based vertical slice. This keeps the intervention visible in the session as a normal tool result while avoiding another model-dependent recovery turn.
