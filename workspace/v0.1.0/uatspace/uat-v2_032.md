# UAT v2 032 incident

- Time: `2026-04-25 11:45:00 JST`
- Model: `qwen3.5:122b` with sidecar `qwen3.5:9b`
- Scenario: exact v2 UAT instruction 1, `Next.js` Space Invaders game.
- Result: failed before completing the required four-instruction run.

## What Happened

The agent scaffolded a Next.js app and the deterministic playable-UI fallback
created a playable `src/app/page.tsx` with canvas, keyboard input, restart
control, and the requested Space Invaders game mode.

However, `package.json` kept the scaffold default:

- `"dev": "next dev"`

The user request explicitly required the app to be startable on port `3011`, so
the output did not fully satisfy the UAT condition.

## Cause

The deterministic playable-UI fallback only replaced the UI entry file. It did
not also reconcile package scripts with explicit launch constraints from the
request, so a successful UI fallback could still leave a non-compliant startup
command.

## Fix Direction

When applying deterministic playable-UI fallback, also inspect `package.json`
for a requested port and update the framework dev script:

- Next.js: `next dev -p <port>`
- Vite React: `vite --host 0.0.0.0 --port <port>`
- Nuxt: `nuxt dev -p <port>`
