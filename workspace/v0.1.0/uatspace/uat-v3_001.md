# uat-v3_001

- 事象
  - Scenario 01 / instruction 3 で `Nuxt.jsで落ち物パズルゲーム` を要求したが、deterministic framework game fallback が `NEON INVADERS` / `mode = 'invaders'` のシューティング系 app.vue を生成した。
- 問題箇所
  - `src/agent/loop_run/quality.rs` の `GameKind::from_request`。
- 根本原因
  - ゲーム種別推定が `テトリス` など一部の固有名に寄っており、`落ち物パズル` のようなカテゴリ表現を falling-block 系として扱えなかった。
- 対策案
  - ゲーム種別ごとのキーワード集合を用意し、固有名だけでなくカテゴリ語・日本語表現・英語表現をまとめて判定する。
- 対策案詳細（仕様）
  - Breakout 系は `breakout`、`brick breaker`、`ボール崩し`、`ブロック崩し`、`レンガ崩し` を扱う。
  - Falling-block 系は `tetris`、`falling block`、`drop puzzle`、`block puzzle`、`テトリス`、`落ち物`、`落ちもの`、`落下`、`パズル`、`積み` を扱う。
  - `Nuxt.jsで落ち物パズルゲーム` が `NEON BLOCKS` / `mode = 'blocks'` を生成する回帰テストを追加する。
