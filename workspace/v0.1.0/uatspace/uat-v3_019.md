# uat-v3_019

## Scenario

- v3 scenario 03
- model: `qwen3.5:122b`
- instruction: React.js household-budget dashboard on port `3011`

## Result

Failed.

## Observed Failure

- The run scaffolded a Vite React app, then repeatedly attempted small edits against `src/App.jsx`.
- The source remained a Vite placeholder shell and became malformed while the run continued through repeated focused-edit recovery.
- The deterministic framework app fallback did not replace the scaffold because the workspace was no longer empty and contained normal scaffold files outside the deterministic fallback file list.

## Cause

The generic app fallback was only applied to empty or very sparse workspaces. Once a full framework scaffold existed, `deterministic_framework_game_files_needed` preserved it unless the scaffold matched the narrow sparse-shell shape. That left placeholder Vite/React apps dependent on the model completing many brittle edit steps.

## Fix Direction

- Keep preserving real existing implementations.
- Allow deterministic app fallback when the existing primary implementation file is still placeholder-like or an incomplete interactive slice.
- Broaden UI intent detection with structural feature terms such as totals, categories, balance, registration, summary, history, save/edit/delete, calculation, and tests.
