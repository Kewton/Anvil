# Support

Use GitHub issues for reproducible bugs, feature requests, and design
discussion.

Before opening an issue, please include:

- Anvil version or commit
- operating system
- model name
- whether `--yes`, `--auto-plan`, or custom `.anvil/config` settings were used
- a minimal prompt and repository shape that reproduces the behavior

For security issues, do not open a public issue. See [SECURITY.md](SECURITY.md).
