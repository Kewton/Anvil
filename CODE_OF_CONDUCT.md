# Code of Conduct

This project uses the Contributor Covenant Code of Conduct, version 2.1.

## Our Standards

Examples of behavior that contributes to a positive environment:

- using welcoming and inclusive language
- respecting different viewpoints and experiences
- giving and gracefully accepting constructive feedback
- focusing on what is best for the community

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- public or private abuse
- publishing others' private information without permission
- conduct that would reasonably be considered inappropriate in a professional
  setting

## Enforcement

Maintainers may remove comments, issues, pull requests, or contributions that
violate this code of conduct. Serious or repeated violations may result in a
temporary or permanent ban from project spaces.

Report concerns privately to the maintainers.
